Display help topics for detailed information about Rei concepts and features.

```bash
rei help [topic]
```

## Usage

Without arguments, lists all available help topics:

```bash
rei help
```

With a topic name, displays detailed information about that topic:

```bash
rei help <topic>
```

## Available Topics

Listed in registry order — the same order `rei help` prints.

| Topic | Description |
|-------|-------------|
| `time` | Understanding time formats and the `--at` flag |
| `custom-properties` | Extending entities with custom metadata fields |
| `dashboard` | Configurable intention panels in the `today` command |
| `intention-filtering` | Filtering options for the `intention list` command |
| `state-machines` | Workflow tracking with state machine properties |
| `views` | Reusable multi-section configurations for displaying intentions |
| `collections` | Curated groups of notes, links, and documents |
| `journal-entries` | Daily tracking with journal entry properties |
| `disruptions` | Tracking recurring interruptions and their patterns |
| `templates` | Template syntax, helpers, and workspace customization |
| `cycles` | Focus cycles, daily adherence, and cycle reports |
| `config` | Configuration file and environment variable reference |
| `review-checkpoints` | Structured review workflow for agent and human work |
| `agent-sessions` | Agent focus modes, sessions, memory, and interactive mode |
| `delegation` | Delegating intentions to agents with scope and autonomy |
| `multi-agent-orchestration` | Scheduled and event-triggered agent work |
| `agent-memory` | Agent memory types, anchors, lifecycle, and supersession |
| `agent-memory-filesystem` | Workspace markdown projection of agent memories |
| `agent-schedules` | Automated recurring and event-triggered agent work |
| `edges` | Typed relationships between entities via predicates |
| `topics` | First-class subjects, attachments, and ontology queries |
| `projects` | Projects as typed topics: scope, review cadence, and Mori sync |
| `reminders` | Scheduling, triage, and the reminders Rei creates for you |
| `kit` | Installing and managing skills and subagents |

## Examples

```bash
# List all help topics
rei help

# Learn about time formats for backdating
rei help time

# Learn about custom properties
rei help custom-properties

# Learn about state machine properties (workflow tracking)
rei help state-machines

# Learn about configurable dashboard panels
rei help dashboard

# Learn about intention views
rei help views

# Learn about collections
rei help collections

# Learn about daily journal entry tracking
rei help journal-entries

# Learn about disruption tracking
rei help disruptions

# Learn about typed relationships between entities
rei help edges

# Learn about first-class topics and ontology queries
rei help topics

# Learn about projects as typed topics
rei help projects

# Learn about reminders and their lifecycle
rei help reminders

# Learn about note and reflection templates
rei help templates

# Learn about intention filtering options
rei help intention-filtering
```

## Notes

- For command-specific help, use `rei <command> --help` instead
- Topic names are case-insensitive
- If an unknown topic is requested, available topics are listed
