Rei uses relative and absolute time formats for the `--at` flag, allowing you to record events that happened in the past.

## Relative Time

Use natural language to specify times relative to now:

```bash
"2 hours ago"       # Two hours before now
"1 hour ago"        # One hour before now
"30 minutes ago"    # Thirty minutes before now
"yesterday"         # Yesterday at current time
"3 days ago"        # Three days before now
```

## Absolute Time

Specify exact dates and times:

```bash
"2024-01-15"        # Specific date at current time
"2024-01-15 14:30"  # Specific date and time
"14:30"             # Today at specific time
```

## Examples

```bash
# Record an action you did 2 hours ago
rei action record -i <id> "Reviewed the draft" --at "2 hours ago"

# Record a habit action for yesterday
rei habit record-action --at yesterday

# Complete a task at a specific time
rei task complete --at "2024-01-15 09:00"

# Record an action at a specific time today
rei action record -i <id> "Standup" --at "14:30"

# Start a focus cycle 30 minutes ago
rei cycle start --at "30 minutes ago"
```

## Future Times

Reminders schedule forward rather than backdating, so their time flags also accept
future expressions: keywords (`now`, `today`, `tomorrow`), bare durations
(`"2 hours"`, `"30 minutes"`), short forms (`2h`, `30m`, `1d`), and ISO 8601 instants.

```bash
rei reminder create "Follow up" --at tomorrow
rei reminder snooze --until 2h
```

See the [Reminders guide](/docs/guides/reminders).

## Commands That Support --at

| Command | Description |
|---------|-------------|
| `action record` | Record an action, optionally backdated |
| `outcome record` | Record an outcome |
| `habit record-action` | Record an action for a habit |
| `task complete` | Mark a task as completed |
| `cycle start` | Start a focus cycle |
| `reminder create` | Schedule a reminder (future times) |
| `project review` | Record a review at the time it happened |
| `<entity> set-property` | Bitemporal property transition (see [Custom Properties](/docs/guides/custom-properties)) |
